# 大学前书目站 · k12-library

阿里云盘 `Library` 中「大学前」分类的书目索引，共 **25 本**，合计 **1.53 GB**。

- 在线访问：https://zrx-11.github.io/k12-library/
- 分类说明：强基与数学启蒙
- 已生成知枢学习伴侣：**1** 本（见首页「本类精讲」）
- `catalog.csv`：本类全量书目（书名、格式、大小、云盘路径）
- `books/`：每本书的档案页（目录、元信息）
- `companions/`：单文件知枢学习伴侣，可离线打开

## 数据口径

由阿里云盘 `Library` 全量 1517 个文件筛出书类文件，按书名归一化去重；小说/文学保留书目但不生成学习页。页面由本地脚本生成，静态托管，无后端依赖。
